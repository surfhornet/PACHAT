Copilot Studio

FACHAT은 ‘판단’을 대신하지 않고, 판단할 수 있는 근거를 정리합니다.

FACHAT은 Fact와 Chat을 결합한 이름입니다. 기사나 게시물의 내용을 입력하면 출처와 관련 근거를 확인하고, 세계 뉴스 API 기반의 보도 흐름을 참고해 보다 신중하게 정보를 바라볼 수 있도록 돕습니다. 이름은 한국어로 “파채”와 비슷하게 들리는 작은 유머도 담고 있습니다.

보여주기용이 아닌,
실제로 설명 가능한 기능들

별도의 입력창은 만들지 않았습니다. 실제 대화와 검증 요청은 위의 Copilot Studio 에이전트 영역에서만 이루어지도록 구성했습니다.

🔎

출처 기반 확인

기사의 출처, 보도 주체, 관련 맥락을 함께 확인하도록 안내합니다.

🌐

세계 뉴스 흐름 비교

세계 뉴스 API를 활용한 관련 보도 분석 방향을 바탕으로 팩트 판단을 돕습니다.

🧭

근거 중심 해설

단순히 맞다, 아니다가 아니라 어떤 근거로 판단해야 하는지 설명합니다.

💬

대화형 팩트체크

궁금한 기사나 주장을 자연어로 물어보고, 이어서 추가 질문할 수 있습니다.

FACHAT 검증 흐름

사용자는 기사나 게시물을 에이전트에게 전달하고, FACHAT은 출처와 근거를 중심으로 신뢰도 판단을 돕는 설명을 제공합니다.

기사 입력

검증하고 싶은 기사 URL, 제목, 내용 또는 게시물 문장을 대화창에 입력합니다.

출처 확인

보도 주체, 발행 맥락, 원문 여부 등 확인해야 할 요소를 살펴봅니다.

근거 탐색

관련 보도와 근거 자료를 바탕으로 주장과 사실을 분리합니다.

신뢰도 분석

과장, 왜곡, 근거 부족 가능성을 대화형 설명으로 정리합니다.

결과 안내

사용자가 스스로 판단할 수 있도록 핵심 근거와 주의점을 알려줍니다.

이렇게 물어보세요

FACHAT은 별도 입력 폼 없이 챗봇 영역 안에서만 대화합니다. 아래 문장을 복사해서 질문해도 좋습니다.

“이 기사 믿어도 될까? 출처와 근거를 확인해줘.”
“이 주장과 관련된 다른 보도 흐름을 비교해줘.”
“이 게시물에서 과장되었거나 확인이 필요한 부분을 찾아줘.”
“팩트와 의견을 나눠서 설명해줘.”

사용 전 안내

FACHAT은 정보 검증을 돕는 AI 도구이며, 최종 판단은 사용자가 여러 출처를 함께 확인해 결정하는 것을 권장합니다.

현재 제공된 에이전트 URL은 파일 첨부가 비활성화된 설정입니다. 텍스트나 URL 중심으로 질문하는 구조가 가장 안정적입니다.
요청한 방식에 맞춰 저장하지 않습니다. 버튼을 누르면 현재 화면에서만 즉시 전환됩니다.
